# Native creature snapshots

`python tools/test-generic-mob-models.py` runs the pinned Minecraft 26.3 model compiler and the C# snapshot/UV/basis/budget checks. It requires the already compiled Fabric classes; it does not launch either game.

The production exporter reads actual client entities by numeric ID plus UUID, calls their original `EntityRenderer.createRenderState` / `submit`, and captures original model parts, native layers, equipped item quads, block quads, and custom quad geometry. All native model access and pose evaluation stays on the client thread. Texture decoding and atomic file writes use one bounded worker. Server requests contain no mutable entities. Dedicated-server request initialization does not load client model classes.

Runtime files: `%LOCALAPPDATA%/Mycraft/entity-models/<session32hex>/<visualKey32hex>.pose`. An `EMP1` pose references an immutable `<appearance32hex>.asset` (`EMA1`), has a monotonic little-endian `Int64` sequence, then per-part visibility, ARGB tint and twelve row-major affine matrix floats. Assets contain bounded original RGBA textures and local vertices/normals/UVs. The pose changes at up to 10 Hz; geometry/pixels are cached by SHA-256 truncated to 128 bits. Original part visibility, hurt tint, Wither side-head animation, native scale and invulnerable texture selection are preserved.

Limits: 16 prioritized creature requests plus 48 optional projectile requests, 256 parts / 16384 original vertices / 8 textures of at most 256 x 256 per snapshot, 256 appearances per session, 4 MiB per asset. Missing initial client tracking/file is normal; the host waits without substituting another creature. No native empty meshes are created for fully transparent eye/overlay parts. Repeated Wither texture switching reuses meshes/materials. Original zero-area cube edge polygons are discarded only after raw-native compilation equivalence is checked. Generic alpha clipping supports both standard ModelPart UVs and rotated item quad UVs, with bounded expansion.

`Fixtures` currently contains actual Wither renderer, Wither skull projectile renderer and arrow renderer snapshots, plus original pig/baby pig/cow/spider/creeper/phantom/ghast/slime model snapshots. The fixture generator isolates GPU constructor dependencies with test-only `Unsafe`; the production mod never uses it. Native geometry is checked against original `Model.renderToBuffer` compiled vertices. Host tests compare every raw vertex/UV with that native oracle, including the MC-to-host reflected coordinate basis. To use a fixture in host smoke, copy its `.asset` to the fixture pose's appearance key (`0123456789abcdef0123456789abcdef.asset`) and its `.pose` to the desired visual key. Change the appearance and sequence when switching fixture models so cache identity stays truthful.

These tests establish original geometry, texture selection, transforms and local format handling. They do not establish a complete live two-game client tracking/appearance acceptance. Minecraft GPU shader effects such as scrolling energy UVs, emissive lighting and specialized translucent blending are not reproduced by the host default material; their native layer geometry/pixels/tints are captured, and gameplay remains native authority.
